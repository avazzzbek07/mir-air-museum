# Museum of Ideas AIIiR · МИР×АИР

Научный сайт групп МиР(б)-1-26, МиР(б)-2-26 и МиР(б)-3-26 (Мехатроника и робототехника, КГТУ им. И. Раззакова): 3D-музей проектов, портфолио с поиском, составы групп, достижения, банк идей и новости.

Сайт: https://avazzzbek07.github.io/mir-air-museum/

## Как добавить проект

Откройте `data.js`, скопируйте любой блок проекта в массиве `ITEMS`, поменяйте поля и положите фото в `img/`. Чтобы проект появился в 3D-музее, добавьте его `id` в список `HALLS` в начале `app.js`.

Данные групп и проектов взяты с сайта МИР×АИР: https://mirlan208.github.io/mir-air-site/

## Объёмные экспонаты

`models.js` содержит лёгкие модели Starys, CyberBuddy, мини-радара, перчатки-мыши, SmartSprout, Пикси и машинки ESP32. Формы и цвета воссозданы вручную по фото из `img/`; это иллюстративные модели, не точные CAD-копии и не автоматическая фотограмметрия. «Камкор» и «Подсолнух» показаны концептуальными моделями из `app.js`, поскольку фотографий этих проектов пока нет. Новые проекты без модели показывают фото на стене; для объёмного экспоната нужно добавить модель в `models.js`.

Статичные детали объединяются по материалу и участкам зала. На устройствах с ограниченной памятью или процессором включаются 30 кадров/с, пониженное разрешение, сокращённая дальность видимости и освещение без теней и карты окружения. При длительных просадках кадров разрешение дополнительно снижается. В скрытой вкладке и обычных разделах 3D не отрисовывается.

## Проверка музея

`tools/verify-museum.mjs` запускает локальный сервер и Chromium через CDP, проверяет залы, объёмные экспонаты, отсутствие исключений и остановку рендера при переходе к проектам. Профили: компьютер, телефон 360×740 (2 ГБ RAM, 4 ядра, замедление CPU ×4), планшет 820×1180. Firebase отключается только тестовым сервером, чтобы проверка была воспроизводимой и не меняла реальные данные. Тест не проверяет авторизацию и модерацию.

Скачайте Three.js версии 0.160.0 в `/tmp/museum-three.module.js`, затем выполните `node tools/verify-museum.mjs`. Путь к Chromium задаётся через `CHROME_PATH`, путь к Three.js — через `THREE_PATH`. Для одного профиля задайте `MUSEUM_PRESET=weak-phone` (или `desktop`, `tablet`). Скриншоты сохраняются в `/tmp/museum-after-*.png`. `--baseline` сравнивает с `app.js` из текущего Git HEAD; запускайте до коммита изменений или из соответствующего checkout.

Эмуляция и программный WebGL помогают проверить функциональность и объём работы рендера, но не гарантируют частоту кадров на настоящих телефонах. Нужна отдельная проверка на реальных устройствах.
