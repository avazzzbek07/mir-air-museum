# Museum of Ideas AIIiR · МИР×АИР

Научный сайт групп МиР(б)-1-26, МиР(б)-2-26 и МиР(б)-3-26 (Мехатроника и робототехника, КГТУ им. И. Раззакова): 3D-музей проектов, портфолио с поиском, составы групп, достижения, банк идей и новости.

Сайт: https://avazzzbek07.github.io/mir-air-museum/

## Как добавить проект

Откройте `data.js`, скопируйте любой блок проекта в массиве `ITEMS`, поменяйте поля и положите фото в `img/`. Чтобы проект появился в 3D-музее, добавьте его `id` в список `HALLS` в начале `app.js`.

Данные групп и проектов взяты с сайта МИР×АИР: https://mirlan208.github.io/mir-air-site/
